## Why (the collision-resistance rethink)
- The 2026-08-03 `CollisionResistant` was *unkeyed + algorithmic* (`∀ A : Alg Unit …`).
  Unkeyed, this is **provably plain injectivity** (`collisionResistant_iff_injective`),
  which is **false for any compressing hash** — so the assumption was unrealistic and
  the `Alg`/`cost` wrapper did no work (`cost` was never read; unbounded ⇒ inert).
- Keying is the standard fix (`def:bus-cr` is keyed): collisions *exist* for every key,
  but a finder handed a *fresh* key cannot *produce* one (no precompute/hardcode). Keying
  separates "exists" from "hard to find" — the actual content of CR.
- Caveat (I8): keyed **perfect** CR is still equivalent to *per-key injectivity*; genuine
  realism needs the efficiency + negligible-probability layer, **deferred to Issue 6**.
  Keying now fixes the structure; it is not a realism claim.
